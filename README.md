
# 🌟 Dr. A.P.J. Abdul Kalam Tribute Page

## 📌 Project Description

This project is a static single-page tribute website dedicated to **Dr. A.P.J. Abdul Kalam**, the former President of India and a renowned aerospace scientist.

The webpage highlights his biography, major achievements, timeline, and legacy using a clean and responsive design.

This project was developed to practice semantic HTML5 and introductory CSS3 styling.

---

## 🎯 Objective

- Practice semantic HTML5 elements.
- Understand basic webpage structure.
- Learn CSS styling and layouts.
- Create a responsive webpage for mobile and desktop.
- Improve HTML and CSS development skills.

---

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- Responsive single-page design.
- Dr. A.P.J. Abdul Kalam image and caption.
- Biography section.
- Major achievements section.

- Legacy section.

## 🧱 HTML Semantic Elements Used

| Element | Purpose |
|---------|---------|
| `<header>` | Website heading and introduction |
| `<main>` | Main page content |
| `<section>` | Organizes content into sections |
| `<figure>` | Displays the tribute image |
| `<figcaption>` | Provides image description |
| `<footer>` | Displays footer information |

## 📱 Responsive Design

The website is designed to work on:

- 💻 Desktop
- 📱 Mobile
- 🖥️ Tablet

A CSS media query is used to adjust font sizes, spacing, and section layouts on smaller screens.

## 🚀 How to Run the Project

1. Download or clone this repository.

2. Open the project folder in VS Code.

3. Make sure the following files are present:
   - `index.html`
   - `style.css`
   - `abj abdul kalam.jfif`

4. Open `index.html` in your browser.

5. Use Live Server in VS Code for a better development experience.
